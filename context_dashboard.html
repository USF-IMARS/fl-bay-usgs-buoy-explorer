How to read this dashboard

A buoy is low when its latest reading falls below the 10th percentile of its own past 5-year record; high when above the 90th percentile; usual otherwise. This is not a fixed salinity/temperature threshold — it adapts to each station’s history and season.

Distribution plots show the QC-filtered 5-year record (all buoys pooled). Station bars show where today’s reading ranks at each buoy (0 = lowest on record, 100 = highest). Interpolated maps show DIVAnd hourly fields on 2026-07-26 for the variable on each page.

Outliers and sentinel values are removed before analysis (salinity 5–55 PSU; temperature 10–40 °C).
